# Dưa Hấu Voice Studio Pro

Kho phát hành chính thức dành cho bộ cài Windows của Dưa Hấu Voice Studio Pro.

- Tải phiên bản mới nhất tại mục [Releases](https://github.com/thuongmmo/voice-studio-releases/releases).
- Mỗi bản phát hành chính thức có chữ ký số Windows và mã SHA-256 để kiểm tra tính toàn vẹn.
- Ứng dụng cần tài khoản/license hợp lệ do Dưa Hấu AI cung cấp qua [chotaikhoan.vn](https://chotaikhoan.vn/).
- Hỗ trợ: [Telegram @duahauaibot](https://t.me/duahauaibot).

Repository này chỉ chứa file cài đặt và ghi chú phát hành, không chứa mã nguồn hay khóa bí mật.

Hiện chưa có bản phát hành công khai. Bản đầu tiên chỉ được đăng sau khi vượt qua quy trình ký số và kiểm tra trên máy Windows sạch.
